# AST-GL: Adaptive Spatiotemporal Graph Laplacian for Ebola Hotspot Detection

Reproducibility package for the manuscript:
**"Adaptive Spatiotemporal Spectral Clustering for Ebola Outbreak Hotspot Detection:
A Self-Tuning Graph Laplacian Framework Validated on Multi-Country Surveillance Data"**

---

## Datasets (download before running)

### 1. West Africa 2014–2016 (Primary)
```bash
git clone --depth 1 https://github.com/cmrivers/ebola.git data/raw/west_africa_2014
```

### 2. DRC North Kivu 2018–2020 (Cross-validation)
```bash
git clone --depth 1 https://github.com/andersen-lab/ebola-drc-epidemiology.git data/raw/drc_north_kivu
```

---

## Installation

```bash
pip install pandas numpy scipy scikit-learn networkx matplotlib geopandas shapely
```

Python 3.9+ recommended. No GPU required. All scripts run on CPU.

---

## Running the full pipeline

Run scripts in order. Each script reads from `data/processed/` outputs
of previous scripts.

```bash
# Step 1-5: Data pipeline
python notebooks/01_consolidate_west_africa.py
python notebooks/02_normalize_signals.py
python notebooks/03_build_matrix_and_sanity_check.py
python notebooks/04_anomaly_detection_correction.py
python notebooks/05_build_adjacency_graph.py

# Step 6-7: Baselines
python notebooks/06_baseline_static_spectral.py
python notebooks/07_baseline_scan_statistic.py      # ~90 seconds

# Step 8: Proposed method
python notebooks/08_adaptive_spatiotemporal_laplacian.py

# Step 9-10: Ablation study
python notebooks/09_ablation_fixed_coupling.py
python notebooks/10_consolidate_ablation_comparison.py

# Step 11-13: Evaluation (11 and 12 are documented flawed designs — kept for audit)
python notebooks/11_head_to_head_validation_v1_FLAWED.py
python notebooks/12_head_to_head_validation_v2_ARI_NMI.py
python notebooks/13_head_to_head_validation_v3_purity.py  # <-- FINAL RESULTS (Table 1)

# Step 14-15: Additional ablations
python notebooks/14_phase_sensitivity_ablation.py
python notebooks/15_transition_responsiveness_test.py     # <-- FINAL RESULTS (Table 2)

# Step 16: DRC cross-validation
python notebooks/16_drc_cross_validation.py               # <-- FINAL RESULTS (Table 4 & 5)
```

**Total runtime:** ~5–8 minutes on a standard laptop.
The scan statistic (Script 07, 999 permutations) is the longest step.

## Revision analyses (response to reviewers, October 2026)

These scripts produce every number, table and figure in the revised manuscript and the Supplementary Material.
Run Scripts 01–08 and 16 first (they write the processed matrices and the DRC matrix), then:

```bash
pip install geopandas matplotlib-scalebar          # extra dependencies for the maps
python notebooks/18_geoboundaries_adjacency_check.py   # polygon adjacency graph + comparison with hand-built graph
python notebooks/17_revision_robust_reanalysis.py      # West Africa: 2 graphs x 3 cleaning variants x 100 k-means seeds (~15 min)
python notebooks/19_revision_drc_reanalysis.py         # DRC: AST-GL + both baselines, 100 seeds (~10 min)
python notebooks/23_revision_k_sensitivity.py          # k = 4..10
python notebooks/20_revision_figures_maps.py           # Figures 2 and 4
python notebooks/21_revision_framework_figure.py       # Figure 1
python notebooks/22_revision_figures_data_drc.py       # Figures 3, 7, 8
python notebooks/24_revision_figures_coupling.py       # Figures 5, 6
```

Key changes relative to the original scripts:

* `src/astgl_core.py` holds one shared implementation. It uses an exact dense eigensolver
  (`numpy.linalg.eigh`) instead of ARPACK (`eigsh`), whose random start vector made results
  machine-dependent, and reports k-means-dependent results over seeds 0–99.
* The primary West Africa graph is derived from geoBoundaries polygons (shared border >= 5 km),
  `data/processed/admin_unit_adjacency_geoboundaries.json`. The original hand-built graph is kept as a
  sensitivity analysis.
* DRC documented ground truth: six zones named in WHO DON 26 June 2020 (Komanda removed).

Boundary files in `data/geo/` are from geoBoundaries (gbOpen, CC BY 4.0; Runfola et al. 2020, PLoS ONE 15:e0231866),
downloaded from `https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/main/releaseData/gbOpen/<ISO>/<ADM>/`.

Outputs: `results/` (CSV/JSON tables), `figures/revised/` (300-dpi PNG figures).
